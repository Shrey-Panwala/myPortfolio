# Shrey Panwala - Portfolio

A responsive AI/ML portfolio for showcasing applied projects, research publication proof, technical skills, GitHub activity, and contact paths.

## Highlights

- Focused positioning for AI/ML roles across computer vision, RAG/LLMs, and federated learning.
- Featured project cards with role and evidence notes instead of only feature lists.
- Research section linked to the ACM DOI and local paper PDF.
- Mobile-first fixes for the hero, navigation, cards, and footer.
- SEO/social metadata, JSON-LD Person schema, and accessible form labels.
- Reduced-motion support for visitors who prefer less animation.

## Tech Stack

- HTML5
- Modular CSS with Grid/Flexbox and CSS variables
- Vanilla JavaScript
- Font Awesome icons
- GitHub stats images for lightweight public activity previews

## Local Preview

Open `index.html` directly in a browser, or run a local static server:

```bash
npx serve .
```

Then open the URL shown by the server.

## Notes

The contact form opens the visitor's email app with a pre-filled message. To make it submit silently from the page, connect a form service such as Formspree, Netlify Forms, EmailJS, or a small backend endpoint.
