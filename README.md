# Shrey Panwala — Portfolio 🚀

A modern, responsive, and performance-optimized professional portfolio website designed to showcase projects, research publications, skills, and open-source contributions. 

Built for high performance and clean aesthetics with a modular, component-based vanilla web architecture.

## 🌟 Features
- **Component-Based Architecture:** HTML and CSS are strictly decoupled into logical components (Hero, About, Projects, Skills, Contact) for easy maintainability.
- **Dynamic Interactions:** Implemented custom Spring-physics button interactions, ripple effects, scroll reveals, and 3D tilting project cards.
- **Fluid UI:** A responsive bento-box design system that seamlessly scales down for mobile and tablet devices.
- **Live Integrations:** Dynamically fetches live GitHub open-source contribution statistics using REST APIs.
- **Editorial Aesthetic:** A dark-mode-first theme characterized by deep contrasts, vibrant gradients, and modern web typography (`Sora` and `Inter`).

## 🛠️ Tech Stack
- **HTML5:** Semantic and accessible document structure.
- **CSS3:** Advanced modular layout (Grid/Flexbox) with native CSS Variables and complex keyframe animations.
- **Vanilla JavaScript:** Zero-dependency interaction handling and intersection observers for scroll animations.
- **FontAwesome:** Scalable vector iconography.

## 📦 Local Deployment
To run this project locally:
1. Clone the repository
2. Run a local development server to test features properly:
   ```bash
   npx serve .
   ```
3. Open `http://localhost:3000` in your web browser.
