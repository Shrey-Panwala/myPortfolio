FedQ-Fraud: A Quantum-Enhanced Federated Learning Framework for Financial Fraud Detection

Published at ACM MobiHoc '25 · Houston, TX, USA 🇺🇸

Built a quantum-noise-injected federated learning framework using a 3-layer GRU with MOON, achieving 97.47% fraud detection accuracy across 4 non-IID clients. Secured model transmission via BBM92 QKD with Homomorphic-style Secure Aggregation against gradient poisoning and data heterogeneity.
